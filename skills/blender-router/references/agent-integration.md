# Agent integration

## Scope

Bind this router to existing 3D, technical-art, animation, environment, look-development, game-asset and creative-production agents. Add a conditional route to orchestration agents. Keep ordinary 2D, web-layout, sales, legal and finance work with their existing routes.

The installed skill's description and `allow_implicit_invocation: true` enable host-selected implicit use. They are not a background process, event listener or guaranteed keyword interception. A binding inside an agent prompt tells that agent to load the router when relevant. Manual commands remain available when automatic selection does not fire.

## Binding text

```text
For Blender/bpy/.blend work, 3D asset production, rigs, materials, rendered 3D
motion, environments or mesh export/QA, load the installed blender-router skill
first, then the specialist skills it selects. Preserve this agent's role,
creative direction, tools, permissions and delivery gates. Use Blender only
when the deliverable needs it; ordinary 2D/CSS/UI motion keeps its current route.
Manual entry: $blender-router <command> <brief>; in Claude Code use
/blender-router <command> <brief> or the installed /blender alias.
Do not report a route plan as executed work. Do not grant new authority to
other agents or share conversation content as part of this integration.
```

## Apply safely

Use the repository's installer to generate a reviewable plan before applying it. Install all 28 original skills plus this router. Name exact agent files; do not bulk-rewrite every persona. The installer appends one marked block, preserves existing bytes, refuses unmanaged collisions, records backups and validates copied bytes. Repeated installation should make no changes.

External hosted agents are not changed by installing local skill files. Report separate verified status for each host. Do not claim ChatGPT personal-skill installation until its own save and verification procedure has succeeded.
